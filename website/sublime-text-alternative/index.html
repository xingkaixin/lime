Lime vs Sublime Text

Capability Lime Sublime Text 4
License & price Free and open source (MIT). Zero license fees or unregistered save popups. Proprietary ($99 license; evaluation mode shows periodic purchase reminders).
Engine & startup Pure Go (CGO_ENABLED=0) rendered natively on the GPU via MyGo. No Electron or webview. Native C++ core with GPU rendering and an embedded Python plugin runtime.
Keybindings & commands Sublime Text command IDs and platform keymaps out of the box, with built-in shortcut conflict checks. Reference keymap, configured through JSON keymap files.
Multiple carets Quick Add Next, add carets above/below, split selection into lines, Find All to multi-caret. Full multi-selection and multi-caret editing.
Goto Anything & palette Fuzzy file switcher with :line jumps, Goto Definition across open tabs, and full Command Palette. Fuzzy file, symbol, and line navigation plus indexed project-wide symbols.
Git workflow Built-in Changes tab (stage & commit), History commit diffs, gutter minidiff, inline & gutter blame, GitHub permalinks. Inline diff markers and git status badges; staging and commit history require Sublime Merge or plugins.
Terminal, diff & preview Integrated terminal, side-by-side / unified file compare, live Markdown preview, and lime CLI included. subl CLI included; terminal, diff view, and Markdown preview rely on third-party packages.
Browser demo The full editor compiles to WebAssembly and runs directly in your browser. Desktop installer only.
Plugins / packages None by design. Everything ships in one fast binary without package breakage. Large Package Control ecosystem (LSP, linters, custom syntaxes, macros).

Honest trade-offs

Choose Lime if you want

  • A free, MIT-licensed native editor that launches instantly and stays out of your way.
  • Sublime Text's exact everyday shortcuts, layouts, Goto Anything, and multiple carets without configuring plugins.
  • Built-in Git staging, commit history diffs, blame annotations, compare views, and an integrated terminal out of the box.
  • One small, auditable Go codebase you can test in the browser before downloading.

Stick with Sublime Text if you rely on

  • Package Control plugins such as LSP servers, linters, or custom Python commands.
  • Sublime-specific macros, snippet ecosystems, or third-party syntax definitions.
  • Very large multi-hundred-megabyte log files tuned specifically for Sublime Text's C++ buffer.
