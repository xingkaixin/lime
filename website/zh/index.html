GPU 原生渲染

基于 MyGo 原生 UI 在 GPU 上直接绘制。没有 WebView，没有 Electron，从按键到文字落屏零冗余开销。

纯 Go 构建

单一 Go 包，CGO_ENABLED=0 零依赖编译到 macOS、Windows，以及你当前正在打开的浏览器 WebAssembly。
