Lime is a native text editor in the manner of Sublime Text: tabs, groups, Goto Anything and multiple carets, on the keys you already know. Written in pure Go.

Native

Drawn on the GPU by MyGo's native UI. No webview, no Electron, nothing between your keys and the text.

Pure Go

One Go package that builds with CGO_ENABLED=0 for macOS, Windows, Linux, and the browser you're reading this in.

Sublime Text's keys

The same commands under the same names, on each platform's own keys. Change any of them.
